# Reporting a security issue

Do not post an unpatched exploit, private game code, credentials, player data, or live purchase details in a public issue.

Use GitHub's private vulnerability reporting for this repository if the feature is enabled. Otherwise contact the repository owner privately using the contact method listed on their GitHub profile. Include only the affected package file, a minimal non-sensitive reproduction, expected impact, and whether the issue affects this skill's guidance or a supplied test fixture.

This project is an instruction package and test fixture collection, not a Roblox security scanner or a guarantee that an experience is secure.
